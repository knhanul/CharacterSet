# 라벤더 미니미 · 영상 제작용 캐릭터 레퍼런스 세트

## 파일 구성
- `01_원본_마스터/00_REF_FACE_MASTER_원본전신.png`: 사용자가 제공한 캐릭터 이미지 원본(무수정). **정체성 최우선 기준**.
- `02_전신_각도/`: 정면, 좌·우 3/4, 좌·우 측면, 후면 총 6장.
- `03_얼굴_각도/`: 정면, 3/4, 측면 얼굴 클로즈업 총 3장.
- `04_표정_참고/`: 웃음, 윙크, 놀람, 고민, 실망, 화남, 피곤, 신남 총 8장.
- `05_미리보기_및_원본시트/`: 각도 시트, 전체 미리보기.

**총 18장의 독립 PNG:** 원본 마스터 1 + 새 각도 9 + 표정 참고 8.

## 사용법
1. 항상 `00_REF_FACE_MASTER_원본전신.png`을 기본 참조로 입력합니다.
2. 장면 구도에 따라 각도 사진 1~2장만 추가합니다.
3. 특정 표정이 필요하면 `04_표정_참고`에서 1장을 참고 이미지로 추가합니다.
4. 생성 결과와 원본의 눈·코·입·얼굴형·머리 실루엣을 비교한 뒤 영상으로 변환합니다.
5. 다음 장면도 다시 마스터를 참조합니다. 이전 생성 결과를 무조건 새로운 원본으로 승격하지 마세요.

## 재사용 프롬프트
첨부한 첫 번째 이미지를 REF_FACE_MASTER(캐릭터 정체성 기준)로 사용하세요. 추가 이미지는 시선 방향/표정/신체 비율만 참고하세요. 큰 갈색 눈, 짙은 갈색의 자연스러운 웨이브 머리, 온화한 미소, 작은 금색 귀걸이, 귀여운 SD 3D 피규어 형태와 얼굴의 고유한 비율을 유지하세요. 기본 라벤더색 맨투맨·베이지 바지·흰 운동화는 장면 요구에 따라 바꿀 수 있습니다. 장소: [배경], 행동: [행동], 표정: [표정], 시점: [각도], 화면비: [9:16 또는 16:9]. 새 인물로 재해석하지 마세요.

## 원본 품질 및 주의점
- 각도별 이미지 9장은 **한 번 생성한 동일한 3x3 시트의 서로 다른 구도**를 실제 분리한 것으로, 사진마다 새로 합성한 것은 아닙니다. 따라서 원본 시트 안의 미세한 인물 차이는 있을 수 있습니다.
- 각도별 PNG 출력 크기는 1024×1024이지만, 각 시트 셀의 원래 상세 정보는 약 418×418 픽셀입니다. 확대는 화질 향상이나 새로운 디테일 생성을 의미하지 않습니다.
- 표정 참고 8장은 다른 AI 생성 시트에서 분리한 **저해상도 표정 가이드**입니다. 최종 영상의 고품질 키프레임보다는 표정 방향을 지정할 때 사용하세요.
- 완전한 얼굴 일치나 연속성은 AI 이미지/영상 모델의 참조 기능에 따라 달라질 수 있어 육안 검수와 재생성이 필요합니다.
- 배경은 흰색으로, 투명 PNG가 아닙니다.
